Retenus d'une séance à l'autre dans ce navigateur, comme le stock coché « Atelier ». Un projet enregistré garde les siens.

Chargement de Python dans le navigateur (une quinzaine de Mo la première fois, ensuite en cache)…

Ctrl+molette : zoomer — clic droit sur une planche : l'épingler — clic droit sur une pièce : la tailler dans une autre planche.

Les planches NEUVES réellement entamées — les chutes, déjà en atelier, n'y figurent jamais. Renseignez le prix d'une planche dans le stock pour obtenir le coût.

    Les restes assez grands pour resservir — la raison d'être du chutier. « Ranger les chutes au stock » met l'atelier à jour comme si le débit était fait.
